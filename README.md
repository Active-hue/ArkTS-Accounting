一款基于 HarmonyOS 原生开发的现代化个人记账应用，使用 ArkTS 声明式 UI 框架构建，提供完整的财务管理解决方案。✨ 核心功能    
- 📊 智能账单管理：支持支出/收入记录，20种分类图标，按日期智能分组展示
- 💰 资产管理：多账户管理，实时计算总资产、总负债和净资产
- 📈 数据可视化：自定义环形图展示分类占比，直观的收支榜单统计
- 🗓️ 灵活筛选：按年月查看历史数据，精准掌握财务状况
- 👤 个人中心：头像上传、昵称修改、记账天数和笔数统计🛠️ 技术亮点
- 纯原生开发，基于 HarmonyOS SDK 5.0.5
- 声明式 UI，使用 @Component、@State 等装饰器实现响应式设计
- Preferences + AppStorage 双层数据持久化方案
- 自定义数字键盘，优化输入体验
- 使用 SVG Path 绘制环形统计图
- 左滑删除、自定义日期选择器等流畅交互
📚 适合学习
本项目代码结构清晰，注释完善，适合 HarmonyOS 初学者学习声明式开发、状态管理、数据持久化等核心技术。包含完整的技术文档，详细讲解实现原理和技术难点。
